-- 05. Understanding Generative AI
1. Richer the training data for LLMs, the smarter and more versatile they become
2. a. Supervised: too expensive
   b. Unsupervised: No goal
   c. Self-supervised: scalable, processes unlabelled data, reduced labelling
        analyze text datasets -> generates labels -> predicts content -> uses contextual cues from surrounding words
3. Four core language modeling techniques
    1. N-grams
    2. Recurrent Neural Networks (RNNs)
    3. Long Short-Term Memory (LSTMs)
    4. Transformers
4. Different stages when building a LLM (not sequential sometimes)
    1. Model design:
        a. select the type of arch to employ (Transformers, CNNs, RNNs, etc)
        b. decide the depth of model
        c. decide the number of layers in the neural network
        d. the total parameters to contain
    2. Dataset engineering (crucial): collection, cleansing, structuring of training data model
    3. Pretraining
    4. Preliminary evaluation
    5. Post-training
    6. Finetuning
    7. Final testing & evaluation
5. Prompt eng  vs Fine tuning vs RAG

-- 08. AI Job position
1. AI Strategist
2. AI Developer
    - Python. Experience on match lib like: numpy, pandas for data cleaning
    - Understanding of statistics, linear algebra, calculus, probability
    - AI research and complex topics like: deep learning, transformers, vector embedding, tokenization
    - Containerization devops practices like docker, API design, cloud
3. AI Engineer
    - NOT focus on AI modeling & training
    - YES focus on integrating AI foundation models
    - Build the BRIDGE, like OpenAI & Google.
    - Optimize AI model's performance: fine tuning, prompt engineering & RAG AI
    - Python. Most data science & AI Lib. pandas, numpy, hugging face, langchain (enables the integration of foundation models into products). Offers the flexibility to select & switch between various LLMs.
    - LangChain helps simplify the AI integration process significantly
    - Vector databases: Pinecone (handling complex data structure like embedding)
    - Solid understanding of LLMs and NLP.
    - Working with cloud services and containerization tools.
